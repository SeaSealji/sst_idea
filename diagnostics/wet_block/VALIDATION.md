# 2026-11-02：算子通过，全球研究假设仍缺预测证据

## 当前模型审计

当前 T1-no-expert：138631 参数，输入 `[B,7,1,244,424]`；stem 输出32通道原分辨率特征。context 的3×3 stride2将空间变为122×212，经过上下文残差块和1×1投影后仍为32通道；再用 `bilinear, align_corners=False` 恢复244×424。与原分辨率skip拼接为64通道，经1×1 merge后加回skip，最后单预测头输出七日距平修正。

未发现现有双上采样。以上源码与CPU合成前向尺寸已核对；**不能由 bilinear 的存在断言它已造成预测瓶颈**。当前填陆和普通卷积也不是内部湿域隔离网络。

## 已执行验证

12项CPU测试通过：16种mask的正交性/分量支持/常数细节零、float32正逆/能量、全湿Haar等价、对角隔离、局部/全局连通区别、奇数干padding、经度接缝、gradcheck与反向、非法输入、任意槽位混合反例、二元归一化插值反例。

仅从已审计的验证归档加载静态180×360 mask，43467湿格；没有读取该归档的误差数组或SST值。沿用当前协议的既有mask，**不称mask仅由训练期构造**。用合成特征检查全球core与halo尺寸：

两个core配对的断连块各涉及24格，即各自43467湿格的 **0.0552%**；不是两组相同格或所有可能对齐的并集。2×2四邻接只有两个对角模式会有多个局部分量。此比例不是预测收益上限，也不能外推到3×3卷积支持、更粗尺度、原生0.25°或实际海岸距离。

## 决策与改进方向

“数学可逆/局部隔离”门槛通过，“现有上下采样导致可纠正的预测损失”尚未证明。因此不启动小波或双上采样训练，不把静态稀疏性称为方法普遍失败。

先按固定训练窗口/区域设计流式有符号残差与湿面梯度统计，区分锋面位移、幅值平滑、二元mask边界与局部组件混合；缺少逐窗口空间场的现有聚合SSE不能反推这些量。对当前3×3 stride2实际支持及恢复路径整体做探针，优先确认是否存在误差集中的可控干预点。

| 对照 | 目的 |
| --- | --- |
| 当前no-expert，保留最佳模型 | 不替换已验证参考 |
| bilinear+Conv / PixelShuffle+Conv / dual，各自匹配容量与计算 | 普通解码容量与采样方式 |
| 普通Haar / 二元wet基 / 分量基，保留相同自由度 | 分开边界归一化与局部支持 |
| 固定随机正交基、相同系数处理 | 排除单纯换基/重参数化 |
| 分量基+支持受限处理 vs 同基+无约束处理 | 验证真正执行隔离的算子，而非仅输入输出mask |

冻结适配器与从头训练分开；若后续进入模型实验，先登记3个配对seed42/43/44、统一val512选模/full2114验证、均匀湿格pooled RMSE与D1–D7/春季/近岸离岸分层，阈值训练前确定，不自动扩seed。FLOPs/更新数/延迟一起报告，不以更多参数和计算冒充几何价值。
