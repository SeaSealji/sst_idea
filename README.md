# SST Idea Research Relay

这是 ChatGPT（论文研究）与 Codex（代码实验）的**公开研究交接仓库**。这里发布论文解析、可检验的创新点、消融计划与实验结论；真实 SST 数据、模型权重、访问密钥、服务器地址/凭据、隐私日志均不得上传。

## 工作方式

1. **ChatGPT / Paper Scout**：每小时阅读一篇已确认顶会发表/接收的时序预测、时空预测、海洋预报或物理机器学习论文。优先 2026 年，缺乏相关性时延伸至 2024–2025 年。核实会议与论文链接，避免重复。
2. 对论文给出真实贡献、与项目的关系，**系统核查最接近的方法**。相似研究并不自动否决 idea，重点是明确新增价值和可验证的差异；确实高度重复时如实指出并提出改造路径。
3. **只有有实际研究价值、可执行的想法才建 GitHub Issue**，标题：`[IDEA][new] 简短中文主题`。每次最多 1 条；其他论文可仅在 ChatGPT 任务报告中总结。若重复则为已有 Issue 补充资料，避免堆砌。
4. **Codex / Experiment Engineer**：每小时读取 Issues。先检查上次实验是否结束；已结束则复核、归档结果，再从有价值的 idea 按优先级依次实现。产生新分支与 PR；不得自动合并。无需对运行中的实验进行实时监控。
5. 数据与模型的实际工作目录由用户**在 Codex 端配置**。本仓库不包含数据集和训练服务配置；不代表已经启动 GPU 任务。

## 目前已知基线（用户汇报，非此仓库重新核验）

- B0: 5-seed validation RMSE **0.519797 ± 0.000779 °C**，参数量 251,415。
- B1 同容量移除物理残差路径的实验曾因 DataLoader worker 退出中止，物理残差路径的**独立有效性尚未验证**。不要基于 B0 数字直接声称物理机制有效。
- 原始测试时段与另一次 2018–2025 测试划分有重叠并已查看结果。论文实验必须分别披露划分，避免错误声称“整个项目测试集从未读取”。
- 多变量单纯 concat 对长 lead D5–D7 的增益曾不明显，优先探索物理作用于预测机制（例如可检验的 lead-dependent conditioning、时空输运/混合过程），不得先假定一定有效。

## 边界

- 不公开原始数据、权重、私密目录、服务器信息或凭据。
- 不以测试集筛选超参数或 idea；优先严格时间划分、验证集和配对种子。
- 训练运行时不得并发抢占 GPU。长作业使用可恢复 checkpoint 和独立日志，操作性故障有限重试；只有真实数据泄漏、目标读取、指标错误等完整性问题才硬停止。
- Code/Experiment 提案以验证价值为先；科学负结果也须如实保留。
